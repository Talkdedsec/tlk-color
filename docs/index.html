Features

Everything in one small window

Color

  • Brightness, contrast and gamma per display or for all displays, per channel (All / R / G / B).
  • Color temperature from 1900 K to 10000 K.
  • Digital vibrance and hue on NVIDIA-connected displays.
  • Before/After: hold the button or Space to see the unmodified picture; Ctrl+Alt+B locks it.

Display

  • Monitor layout map, resolution, refresh rate, scale % and orientation.
  • Custom resolution (W × H @ Hz) and 4:3 presets: 1440×1080, 1280×960, 1024×768.
  • Scaling modes: keep aspect, full screen, center, monitor.
  • Mode changes roll back automatically unless you confirm within 15 seconds.

Profiles & hotkeys

  • Save profiles and apply them with Ctrl+Alt+1…9.
  • Ctrl+Alt+0 resets, Ctrl+Alt+C toggles on/off.
  • Tray icon and start with Windows.
  • Re-applies your settings after display, session or sleep changes.
  • UI in English and Turkish.

Install

Requirements

  • Windows 10 or 11, x64
  • .NET 9 Desktop Runtime
  • NVIDIA GPU: only for vibrance, hue and driver-level custom resolutions

Steps

  1. Install the .NET 9 Desktop Runtime if you don't have it: dotnet.microsoft.com
  2. Download tlk-color.exe
  3. Run it, pick a display, tune and save a profile.

Good to know

  • Gamma applies to the whole monitor, not to a single window.
  • Some fullscreen games reset the gamma.
  • Digital vibrance, hue and driver-level custom resolutions need an NVIDIA GPU.
