# Security Policy

## English

Do not open a public issue for security vulnerabilities.

Report them privately via the repository's **Security** tab > **Report a vulnerability**, or email talkdedsec@proton.me.

Supported version: the latest release.

## Türkçe

Güvenlik açıkları için herkese açık issue açmayın.

Özel olarak bildirin: deponun **Security** sekmesi > **Report a vulnerability** ya da talkdedsec@proton.me adresine e-posta.

Desteklenen sürüm: son sürüm.
